# Portfolio Website

A modern portfolio website built with Next.js and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deployment

This project is ready to deploy to Vercel without any custom database, CMS, or checkout service setup.

## Notes

- OpenAI features are optional and can be enabled through environment variables when needed.
- Blog content is served from local project data in this build.
- Authentication is simplified for static deployment.
